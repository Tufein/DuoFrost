# DuoFrost 2.5.1 — startup fix

This patch fixes a welcome-window leak reported while opening stable 2.5.0 on
an AYN Thor Max running Android 13. When Android recreates the app screen, the
old alert now closes. The new screen shows the welcome again until you confirm
it; recreating the screen does not count as accepting the message.

The lighting features, presets and settings from 2.5.0 remain unchanged.
See the [2.5.0 user guide](2.5.0.md) for setup and features.

## Update

1. Export a full backup and keep it outside the app.
2. Install [DuoFrost-2.5.1.apk](https://github.com/Tufein/DuoFrost/releases/download/v2.5.1/DuoFrost-2.5.1.apk)
   over your existing production DuoFrost installation.
3. Open DuoFrost and confirm the welcome message if it appears.

Production 2.1.0, 2.3.0, the 2.5.0 alphas and 2.5.0 update in place using the
same signing key. Original Version 1 and Version 2 still need the
[one-time backup and reinstall procedure](../README.md).
