# DuoFrost 2.6.0 — themes, backups and guided setup

Stable release. Update production 2.5.1 in place: the production APK must be
signed with the same release key as 2.5.1, which the maintainer confirms before
publishing.

## Update

1. Export a full backup and keep it outside the app.
2. Install **DuoFrost-2.6.0.apk** over 2.5.1. Presets and settings are kept.
3. Check your lighting. Automatic backup folders and their permissions are local to
   the device: choose the folder again if you reinstall.

Original Version 1 and Version 2 still need the one-time backup and reinstall
procedure in the [README](https://github.com/Tufein/DuoFrost#install-or-update).

## What changed since 2.5.1

- **Guided setup:** permissions, six LED checks and a final screen. Replay it from
  Device settings.
- **Theme editor:** contrast-checked custom palettes, five more appearance palettes,
  independent theme transfer, and themes in full backups.
- **Dashboard layout:** reorder the two main cards and hide optional sections.
- **Automatic backups:** opt in, choose a folder, and keep full backups after
  important changes.
- **Preset transitions** (instant or a bounded colour blend) and a **Smart Scenes
  simulator** that previews a choice without changing lighting.
- **Notifications:** hide the lighting notification in Android's channel settings
  while lighting keeps running.
- **Audio effects** request Android's audio permission. If it is denied, other
  effects keep working.
- **Screen readout test** on the LED test screen. It runs only when tapped and does
  not change lighting. It writes one full-screen capture to app storage for a moment,
  then deletes it after sampling.
- **Fixes:** Smart Scenes, undo and import fixes from the 2.5.0 review, and an
  accessibility capture fix contributed by mleo2003.
