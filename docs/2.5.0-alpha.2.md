# DuoFrost 2.5.0-alpha.2

The second development build toward 2.5.0 makes presets easier to organise,
preview and import, while improving Smart Scenes stability. It includes the
Smart Scenes, app groups and temporary choices from [alpha.1](2.5.0-alpha.1.md).

## Organise your preset library

Open a preset's **⋮** menu to add it to **Favourites**, choose its **Collections**,
preview its effect or edit its lighting. Favourites appear first. Use the filter
chips and search together to find a look quickly.

The **Collections** button lets you create, rename and remove collections. A
preset can belong to several collections; removing a collection keeps its
presets. Browsing, filtering and organising the library leave your lighting
unchanged. Tap the preset card itself to apply it when manual switching is active.

Large libraries show the first 40 matching presets. **Show more presets** adds
another 40, keeping the initial screen lighter.

## Preview without applying

Choose **Preview effect** from the preset menu to view its saved colours and
brightness on two illustrated lighting rings. Supported animations can be played
or paused. Previews respect Android's disabled-animation setting and stop
animating when the preview screen leaves the foreground.

This is a visual approximation. Ambient, audio, sensor-driven, random and
flashing effects use still illustrations with an explanation. The preview does
not capture your screen or audio, request permissions, change saved settings or
send commands to the LEDs. Check the final look on your AYN device.

## Review a community preset import

Choose a preset bundle through the existing import control. Before saving:

1. Select the presets you want to keep.
2. Choose how matching names should be handled: **Add separate copies**,
   **Replace matching user presets**, or **Skip matching names**.
3. Optionally enable **Also import app assignments for selected presets**.
4. Check the added/replaced/skipped summary, then save.

Separate copies are the default and receive unique names. Replacing a matching
user preset keeps its existing identity and scene links. Presets managed by apps
or plugins are kept; replacement mode adds a separate copy instead.

App assignments are off by default. When enabled, only assignments for the
selected imported presets are included, with copied names adjusted. They are
merged into your existing assignments; assignments for the same apps can change.
Cancel leaves the library and assignments unchanged.

Saving never starts stopped lighting. Running automation can use updated presets
or app assignments. The review supports bundles of up to 500 presets and a
resulting library of up to 2,000 presets.

## Undo an import or deletion

After an eligible preset import or deletion, an **Undo** button appears in the
library for ten minutes. It restores the saved presets, favourites, collection
memberships and app assignments from before that action. Artwork needed for
recovery is retained while undo remains available.

There is one pending undo. A newer eligible action replaces it, and later changes
to the library or app assignments make it unavailable so they are preserved.
Very large libraries can exceed the temporary recovery limit; DuoFrost tells you
when undo cannot be offered. Keep a full backup before large changes or alpha
updates.

Full backups with **Profiles** selected now include favourites and collections,
alongside scene rules and app groups. Temporary undo is not exported. Restoring
profiles or images from a full backup clears it; restoring only themes or settings
keeps it.

## More reliable Smart Scenes

App and game scene changes briefly settle before switching, reducing reactions
to momentary foreground changes. The first recognised app remains immediate;
revoking Usage Access clears app-dependent scene context immediately. Time,
battery and temporary-choice expiry continue to be evaluated directly.

Scene settings are reused while unchanged, and related preference changes are
handled together. App detection caches use elapsed time, so changing the device
clock cannot leave stale entries active. The scene screen's temporary-choice
countdown updates while visible.

## Testing and updates

The build passed 366 automated tests and 26 Android screen tests, release lint,
signature verification and an in-place update from alpha.1. Physical LED output,
capture and firmware behaviour require AYN hardware testing. Please include your AYN
model, Android/firmware version and reproduction steps in feedback.

The production-signed alpha uses the release key introduced in 2.1.0. Back up
first when testing an alpha. Original Version 1 and Version 2 users still need
the [one-time backup and reinstall procedure](../README.md). A debug APK installs
separately and keeps separate settings. Run one LED controller at a time.

General scene transitions and creative palette tools remain future work; see
the [roadmap](roadmap-2.5.0.md) and [feature research](feature-research-2.5.0.md).
