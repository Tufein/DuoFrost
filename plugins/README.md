# DuoFrost plugin catalog

This catalog is maintained in https://github.com/Tufein/DuoFrost.
It starts empty: no third-party plugin has been verified against DuoFrost's
new package and API identity yet. Do not install an upstream BiFrost-only
plugin expecting it to control DuoFrost.

Preset archive schema markers remain compatible with BiFrost. Live integrations
must target `io.github.tufein.duofrost` and its documented API (INTEGRATING.md).
