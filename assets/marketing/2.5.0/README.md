# DuoFrost 2.5.0 release images

`duofrost-2.5.0-release-cover.png` is the Reddit release cover. It includes the
version, AYN-devices tagline, three example screenshot panels and the hidden
Recent apps feature. The exact generation prompt is in `cover-prompt.txt`.

The cover was created with the built-in image-generation tool using the three
2.5.0 emulator screenshots as inputs. It is promotional art. Use the separate
original screenshots in `assets/screenshots/` to show the actual interface.

Suggested gallery order and captions: [Reddit images](../../../docs/reddit-2.5.0-assets.md).

[Download the complete Reddit package](DuoFrost-2.5.0-Reddit.zip) for the title,
post body, captions, release cover and three original screenshots.
